# Committed demotion list — the human override layer for the WORDHOOD gate.
#
# `<word> <reason>`, `#` comments, merged over the pinned upstream inputs by
# `npm run build:index` before every other stage (ADR-0011, amended). Unlike
# words.txt and names.txt — which are regenerable and uncommitted — this file is
# committed and survives a fresh clone.
#
#   - `proper-noun`      the word is a name. It loses wordhood and joins the
#                        names list, so it is rejected AS a name: `Kate`
#                        obviously rhymes with `ate` and a silent refusal reads
#                        as a bug (CONTEXT.md).
#   - `not-a-known-word` the word is junk with wordhood — an abbreviation, a
#                        misspelling, a Latin fragment. It loses wordhood and is
#                        rejected as a non-word. It is NOT called a name.
#
# The list is deliberately BOUNDED: these are the words a human read, surfaced by
# the #89 measurement (in-band Seed families surviving on three or fewer native
# words, plus every Seed representative of three characters or fewer) and by #51.
# It is not, and must not become, "make the names filter correct" — there is
# always another surname in the word list. Widening it means measuring again.
#
# A word is left alone unless it is clearly not an English word. Ambiguous cases
# stay: `hertz` is the SI unit, `laird` a Scottish landowner, `schmalz` a variant
# of `schmaltz`, `bortz` an industrial diamond, `els` the plural of `el`,
# `schilling` a currency. All are surnames too; all are also words, so all keep
# their wordhood. Likewise the foreign forms and interjections ADR-0008 groups
# with names — `mesdames`, `messieurs`, `zounds`, `congrats` — are real words.
