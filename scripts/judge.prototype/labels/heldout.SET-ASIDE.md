# heldout.labels.json is set aside: never score against it, never bring it to main

These are the maintainer's blind labels on the first held-out set (`heldout.json`, 198 pairs).
They were made before [#232](https://github.com/jkenna-Colgate/rhyme-bee/issues/232) said which rhymes score, and the maintainer found them inconsistent:
`stylish` for `dish` was a full rhyme while `tarnish` was weak, and `pollution` for `delusion` rhymed while `revision` did not.
#231 set them aside and cut `heldout-2` as a fresh set.

They are kept here, on the #231 record, because this was the only copy.
The label sets on `main` are listed in [#248](https://github.com/jkenna-Colgate/rhyme-bee/issues/248); this one is deliberately not among them.
